# Pong: 2026 Remake

A neon-drenched, chaotic reimagining of the classic game of Pong. Built with HTML5 Canvas and JavaScript.

## 🎮 How to Play
*   **Player 1 (Left):** w and s keys (or Left Stick on Gamepad 1)
*   **Player 2 (Right):** Up and Down Arrow keys (or Left Stick on Gamepad 2)
*   **Pause:** Spacebar (or the + button on Gamepad)

## ⚡ Features
*   **Speed Escalation:** The longer the rally, a bolting surprise approaches. 
*   **Chaos Power-ups:** Grab the green "?" boxes, Some will help you, harm you, help the other guy, who knows.
*   **Freezing ghosts, Boxes that clone things, and more:** Every match is unpredictable.
*   **Neon Aesthetic:** CRT scanlines, glowing text, and particle explosions.

## 🛠️ Tech Stack
*   HTML5 Canvas
*   Vanilla JavaScript
*   CSS Animations
